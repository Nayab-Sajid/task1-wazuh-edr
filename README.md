# Task 1 – Wazuh EDR Deployment

Internee.pk Cybersecurity Internship

## Objective
Protect Internee.pk's devices and servers from malware and unauthorized access by deploying an EDR (Endpoint Detection and Response) tool, monitoring file integrity and user activity, and automating alerts for suspicious behavior.

## What's in this repo
- **Task1_Wazuh_EDR_Report.docx** – Report covering the Wazuh deployment and each requirement

## What was done
1. **Deployed Wazuh** – Accessed a live Wazuh management dashboard through a guided lab environment (TryHackMe).
2. **Monitored file integrity and user activity** – Explored the Integrity Monitoring (FIM) and Security Events modules.
3. **Automated alerts** – Reviewed Wazuh's built-in Rules, which automatically flag and score suspicious activity by severity.
4. **Data sources** – Reviewed where endpoint agents (with Sysmon) feed data into Wazuh, and browsed MalwareBazaar for public threat intelligence (sample listings only, no files downloaded).

## Note
This lab's demo agents are disconnected by design, so some modules show no live events — this is expected, not an error, and is explained in the report.
